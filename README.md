### 🏭 Real-Time Industrial Digital Twin Dashboard
> **Live factory monitoring system with sub-100ms latency**

[![Live Demo](https://img.shields.io/badge/🟢%20Live%20Demo-00C853?style=for-the-badge)](https://realtime-digital-twin-dashboard.onrender.com)
[![Source Code](https://img.shields.io/badge/Source%20Code-181717?style=for-the-badge&logo=github)](https://github.com/nikhilc1910/realtime-digital-twin-dashboard)

A **production-grade Industrial IoT Digital Twin** built for factory floor monitoring. The system ingests live machine telemetry, detects anomalies in real time, and visualises plant health across 15 machines with zero polling.

**Architecture highlights:**
- **MQTT (QoS 1/2)** → Eclipse Mosquitto → Node.js subscriber → Redis (state cache) + PostgreSQL (time-series) → Socket.IO → React dashboard
- **5 alert types:** HIGH_TEMPERATURE, HIGH_VIBRATION, DOWNTIME, CONNECTIVITY, SAFETY_VIOLATION
- **Redis deduplication** prevents alert storms; alerts auto-resolve when conditions normalise
- **Dual downtime detection:** MQTT status payload + 60 s heartbeat timeout
- **CCTV integration:** camera event endpoint generates SAFETY_VIOLATION alerts with confidence scores
- **OEE CSV export**, Docker Compose 5-service stack, Zod schema validation, Pino structured logging

| Metric | Value |
|---|---|
| Machines Monitored | 15 across 3 lines |
| MQTT Update Rate | 1 Hz per machine |
| WebSocket Latency | < 100 ms |
| Redis Cache Hit Rate | 99.2% |
| Test Coverage | 4/4 suites passing |

**Stack:** `Node.js` `TypeScript` `React` `MQTT` `Redis` `PostgreSQL` `Socket.IO` `Docker` `Zod` `Jest`
